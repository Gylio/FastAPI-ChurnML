# Python Web + 机器学习模型部署(练习版)

## 项目简介：

训练 用户流失预测 的机器学习模型，使用 Python Web框架部署为Web服务，实现模型版本管理、预测、监控，支持批量预测与结果可视化，聚焦 机器学习模型与Web系统 的集成设计。

## 功能介绍：

#### # [初版v0.1.0]

##### 通过参数输入、CSV/Excel批量上传，实现预测结果可视化，准确率 ≥85%

## 项目特点：

### 1、模型多版本共存、切换，有模型训练报告

### 2、实现模型预测准确率统计、请求量统计、异常请求记录，日志分级管理，及时发现模型异常

### 3、封装数据与处理组件，实现 输入数据的校验、缺失值/异常值的处理


## 技术使用：

### 核心语言：Python 3.12

### Web框架：FastAPI (满足高性能、异步 和 自动文档生成 需求)

### 机器学习：scikit-learn，pandas，numpy，joblib

### 数据处理：pydantic

### 可视化：ECharts (前端渲染)

### 测试工具：pytest (单元测试)，locust (性能/并发测试)，coverage.py (覆盖率统计)

### 版本控制：Github

### *容器化(暂定)：Docker，Docker Compose
